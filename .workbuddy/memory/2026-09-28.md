## Hero 3D 模型切换：FBX → Jab Cross.glb（GLTFLoader）

- 用户先要求用 `/Users/justrun/3dmodel/Jab Cross.fbx` + FBXLoader；FBX 贴图为外部 `.fbm` 路径引用（Video 内容为空），FBXLoader 拿不到图像 → 黑剪影；用本地 PNG 手动绑材质后颜色正常（fbx-hero-2 截图验证）。
- 最终用户改主意：用 Blender 导出的 `/Users/justrun/3dmodel/Jab Cross.glb`（20.6MB）+ GLTFLoader，已复制到 `public/models/jab-cross.glb`。
- `BoxingBoy3D.tsx` 关键实现：
  - GLTFLoader 加载 `/models/jab-cross.glb`，AnimationMixer 播放内嵌 `Armature|mixamo.com|Layer0`（99 通道 Jab Cross）。
  - GLB 内含遗留灰色占位 Cube（无贴图、无骨骼，node 名 "Cube"）→ 运行时 `visible=false` 隐藏。
  - **蒙皮包围盒陷阱**：SkinnedMesh 的 bind-pose bbox 是 mesh 本地 cm 单位（高~98），必须 `bbox.applyMatrix4(mesh.matrixWorld)`（含 Armature 0.01 缩放）转世界空间后再 union，否则 scale 算错（模型小到看不见或巨大）。three r183 的 `SkinnedMesh.computeBoundingBox()` 可用。
  - **贴图偶发解码失败**：GLB 内嵌 4096×4096 PNG 通过 blob URL 解码在 app 页偶发失败（GLTFLoader 把失败纹理设为 **null** 而非空 image！诊断条件必须是 `!m.map`）。兜底：用 TextureLoader 加载本地 `boxing-basecolor.jpg`(2048, 913KB) / `boxing-normal.jpg`，`flipY=false`（glTF UV 约定），手动赋给材质。
  - 兜底贴图由原 PNG 用 `sips -Z 2048 -s format jpeg` 生成。
- **环境坑**：本机到 Shopify API 网络不稳，SSR 流式响应会中途断掉返回空文档（htmlLen≈39，body 空，但 tab title 已刷出），表现为页面全白。非前端代码问题，重试加载即可。控制台报 `SWR in sub-request failed: Network connection lost`。

## Shopify 店铺现状盘点（直接查 Storefront API 得到）

- 店铺 domain 前缀 `just-run...`（.env 内 PUBLIC_STORE_DOMAIN / PUBLIC_STOREFRONT_API_TOKEN）。
- 排查方法：`curl https://$DOMAIN/api/2026-04/graphql.json -H "X-Shopify-Storefront-Access-Token: $TOKEN" -d '{"query":"..."}'`。注意 Storefront API 的 Collection 类型**没有 productsCount 字段**。
- API 可见的 collections 只有 2 个：`frontpage`（"Home page" 默认类目，0 商品）、`boxing-gloves`（2 商品）。用户说在 Admin 建了两个，第二个查不到 → **未发布到 Headless/Storefront sales channel**（这是 Hydrogen 站点看不到新类目的标准原因）。
- 商品共 3 个：Adult White & Gold / Kids' Tiger-Print（都在 boxing-gloves）、Adult Yellow Fingerless MMA（**不属于任何类目**）。
- 首页只取 1 个类目：`collections(first:1, sortKey:UPDATED_AT, reverse:true)` → 即使都发布也只有 1 个显示；建议改为「Shop by Category」多类目网格。
- Header 导航来自 Admin → Online Store → Navigation（root loader 的 headerMenu 查询），建类目**不会**自动进菜单。
- **主菜单不显示修复**：两个叠加原因 ① root.tsx 里 HEADER/FOOTER 查询用 `CacheLong()`（1h 内存缓存），Admin 改菜单后 SSR 返回旧缓存 → dev 下改 `CacheNone()`、prod 保持 `CacheLong()`；② Header.tsx `activeLinkStyle` 写死 `color:'black'`，深色主题下激活链接隐形 → 改用 `var(--color-text)` / `var(--color-muted)`。验证：SSR nav 含 Home + Boxing Gloves。
